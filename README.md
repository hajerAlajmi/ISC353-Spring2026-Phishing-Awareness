# ISC353-Spring2026-Phishing-Simulation-Awareness-Platform
ISC353 Phishing and Awareness Project

Overview:

This project was developed as part of ISC353 - Information Systems Security at Kuwait University. The purpose of this project is to simulate real-world phishing attacks in a controlled, ethical, and educational environment to evaluate user awareness and behaviour when exposed to phishing attempts.
The system mimics how attackers design phishing campaigns and how users interact with them. It tracks key actions such as:

•	Email delivery 

•	Email opens 

•	Link clicks 

•	Data submission 

All activities were conducted with prior user consent, and no real sensitive data was stored or misused. 


Project Objectives

The main objectives of this project are:

•	To understand how phishing attacks are designed and executed 

•	To simulate realistic phishing scenarios using different techniques 

•	To evaluate how users respond to phishing emails 

•	To analyse user behaviour based on collected data 

•	To raise awareness about phishing risks and prevention 



System Architecture & Workflow

The phishing simulation follows a structured workflow that reflects real-world attack scenarios:

1.	The attacker (student) prepares the environment using Kali Linux
3.	GoPhish is used to design and manage phishing campaigns 
4.	Email templates are created with realistic content 
5.	Emails are sent using Gmail SMTP to appear legitimate 
6.	The target user receives the email in their inbox 
7.	When the user clicks the link, they are redirected through ngrok 
8.	The user lands on a fake webpage (landing page) 
9.	User interaction (clicks or data entry) is recorded 
10.	All results are displayed in the GoPhish dashboard for analysis 
This workflow allows real-time monitoring and evaluation of phishing effectiveness.

 Email Templates Design
 
Multiple phishing email templates were created to simulate different real-life scenarios.

1.	KU Financial Survey Email (Arabic)
This email mimics an official Kuwait University message to increase trust and credibility.
<p>عزيزي العميل،</p>
<p>حرصًا من إدارة الشؤون المالية في جامعة الكويت...</p>

<!-- GoPhish dynamic URL -->
<p><a href="{{.URL}}">اضغط هنا لتعبئة الاستبيان</a></p>

<!-- Tracking pixel -->
<p>{{.Tracker}}</p>
2.	ISC 450 Project Email
This email targets students using a familiar academic context.
<p>Hi Dana</p>
<p>I uploaded the ISC 450 project...</p>

<p><a href="{{.URL}}">ISC450 Project</a></p>

<p>{{.Tracker}}</p>
 Key Variables Used
 
•	{{.URL}} → unique phishing link generated by GoPhish 

•	{{.Tracker}} → hidden tracking pixel to detect email opens 

These variables are essential for tracking user interaction.
